# Pilih Chart (25 tipe data)

Aturan pertama: chart cuma kalau datanya memang butuh dibandingkan secara visual. Angka tunggal -> stat card. Dua angka -> kalimat.

- **Trend Over Time** -> Line Chart (alternatif: Area Chart, Smooth Area). Jangan dipakai kalau: Fewer than 4 data points (use stat card); more than 6 series (visual noise); no time dimension exists. Min data: <1000 pts: SVG; ≥1000 pts: Canvas + downsampling; >10000: aggregate to intervals. A11y: Use solid, dashed, and dotted line styles plus direct series labels; never distinguish series by hue alone.
- **Compare Categories** -> Bar Chart (Horizontal or Vertical) (alternatif: Column Chart, Grouped Bar). Jangan dipakai kalau: Categories > 15 (use table or search); data has time dimension (use line); showing proportions (use waffle/stacked). Min data: <20 categories: vertical bar; 20-50: horizontal bar; >50: paginated table. A11y: Use direct category/value labels and group outlines or patterns; never encode category solely by bar color. Do not rely on color alone.
- **Part-to-Whole** -> Pie Chart or Donut (alternatif: Stacked Bar, Waffle Chart). Jangan dipakai kalau: Categories > 5; slice differences < 5% (visually indistinguishable); user needs precise values; accessibility-first context. Min data: Max 6 slices; beyond that switch to stacked bar 100%. A11y: Pie charts do not inherently fail WCAG; unlabeled color-only slices are inaccessible. Use direct labels and patterns, with a non-pie fallback. Do not rely on color alone.
- **Correlation / Distribution** -> Scatter Plot or Bubble Chart (alternatif: Heat Map, Matrix). Jangan dipakai kalau: Variables are categorical (use grouped bar); fewer than 20 points (patterns aren't meaningful); mobile-primary context. Min data: <500 pts: SVG; 500-5000: Canvas at 0.6-0.8 opacity; >5000: hexbin or aggregate first. A11y: Combine marker shapes with direct group labels; color may reinforce but must not be the only distinction.
- **Heatmap / Intensity** -> Heat Map or Choropleth (alternatif: Grid Heat Map, Bubble Heat). Jangan dipakai kalau: Fewer than 20 cells (use bar); user needs to read exact values; colorblind users without pattern fallback. Min data: Up to 10,000 cells efficiently; beyond that aggregate; calendar heatmap: 365 cells max per SVG. A11y: Print values or symbols in cells and use texture/labels in addition to the color scale. Do not rely on color alone.
- **Geographic Data** -> Choropleth Map or Bubble Map (alternatif: Geographic Heat Map). Jangan dipakai kalau: Regions have very different sizes making visual comparison misleading (use bar); mobile-primary context. Min data: <1000 regions: SVG; ≥1000: Canvas/WebGL (Deck.gl); global maps: tile-based rendering. A11y: Label regions directly and pair fills with boundaries or patterns; location meaning cannot depend on color alone.
- **Funnel / Flow** -> Funnel Chart or Sankey (alternatif: Waterfall (for flows)). Jangan dipakai kalau: Stages aren't sequential; values don't decrease monotonically (use bar); fewer than 3 stages. Min data: 3-8 stages optimal; beyond 8 stages group minor steps into 'Other'. A11y: Keep stage names and values visible and distinguish stages with text and boundaries, not only a gradient. Do not rely on color alone.
- **Performance vs Target** -> Gauge Chart or Bullet Chart (alternatif: Dial, Thermometer). Jangan dipakai kalau: No target or benchmark exists; comparing multiple KPIs at once (use bullet chart grid). Min data: Single metric per gauge; for 3+ KPIs use bullet chart grid layout. A11y: Place the number and target text beside the gauge and label threshold zones; red/yellow/green alone is insufficient.
- **Time-Series Forecast** -> Line with Confidence Band (alternatif: Ribbon Chart). Jangan dipakai kalau: No historical baseline; prediction confidence is too low to be useful; audience is not data-literate. Min data: Keep historical window to 30-90 days for readability; forecast horizon ≤ 30% of visible x-axis range. A11y: Use solid actual and dashed forecast lines, direct labels, and a named confidence range; hue alone is insufficient.
- **Anomaly Detection** -> Line Chart with Highlights (alternatif: Scatter with Alert). Jangan dipakai kalau: Anomalies are predefined categories (use bar with highlight); real-time context without a pause control. Min data: Stream at ≤60fps with Canvas; batch: up to 10,000 pts; mark anomalies as a separate data layer. A11y: Mark anomalies with a distinct shape and text annotation as well as color. Do not rely on color alone.
- **Hierarchical / Nested Data** -> Treemap (alternatif: Sunburst, Nested Donut, Icicle). Jangan dipakai kalau: Hierarchy depth > 3 levels (too complex to read); user needs to compare sibling values precisely. Min data: <200 nodes: SVG; 200-1000: Canvas; >1000: paginate or pre-filter before rendering. A11y: Label hierarchy nodes and use borders/patterns as well as hue; make the tree table the primary accessible view. Do not rely on color alone.
- **Flow / Process Data** -> Sankey Diagram (alternatif: Alluvial, Chord Diagram). Jangan dipakai kalau: Flow directions form loops (use network graph); fewer than 3 source-target pairs; mobile-primary context. Min data: <50 flows: SVG; ≥50: Canvas; >200 flows: aggregate minor flows into 'Other' node. A11y: Label source, target, and value; use line style or node symbols in addition to gradient color. Do not rely on color alone.
- **Cumulative Changes** -> Waterfall Chart (alternatif: Stacked Bar, Cascade). Jangan dipakai kalau: Changes are not additive; more than 12 bars (readability breaks); audience expects a simple total. Min data: 4-12 bars optimal; beyond 12 aggregate minor items into a single 'Other' bar. A11y: Pair increase/decrease bars with signed values and directional icons, not red/green alone. Do not rely on color alone.
- **Multi-Variable Comparison** -> Radar / Spider Chart (alternatif: Parallel Coordinates, Grouped Bar). Jangan dipakai kalau: Axes > 8 (unreadable); values need precise comparison (use grouped bar); audience unfamiliar with radar charts. Min data: 2-3 datasets maximum per chart; 5-8 axes; beyond 8 axes switch to parallel coordinates. A11y: Use line styles, point shapes, and direct series labels in addition to color. Do not rely on color alone.
- **Stock / Trading OHLC** -> Candlestick Chart (alternatif: OHLC Bar, Heikin-Ashi). Jangan dipakai kalau: Non-financial audience; no OHLC data available (use line chart); accessibility-first context. Min data: Real-time: Canvas required. Historical: paginate by time range. Max 500 candles visible at once. A11y: Use filled versus hollow candles and OHLC text values; bullish/bearish meaning cannot depend on color. Do not rely on color alone.
- **Relationship / Connection Data** -> Network Graph (alternatif: Hierarchical Tree, Adjacency Matrix). Jangan dipakai kalau: Node count > 500 without clustering pre-applied; user needs precise connection counts; mobile context. Min data: ≤100 nodes: SVG; 101-500: Canvas; >500: must apply clustering/LOD before rendering. A11y: Use labeled node types, shapes, and edge styles in addition to color; the adjacency view is the accessible source of truth. Do not rely on color alone.
- **Distribution / Statistical** -> Box Plot (alternatif: Violin Plot, Beeswarm). Jangan dipakai kalau: Fewer than 20 data points per group (distribution is not meaningful); audience unfamiliar with statistical charts. Min data: Any sample size; aggregated representation so rendering is ⚡ Excellent at any volume. A11y: Label median, quartiles, whiskers, and outliers directly; do not use color alone for statistical roles.
- **Performance vs Target (Compact)** -> Bullet Chart (alternatif: Gauge, Progress Bar). Jangan dipakai kalau: Single KPI with emphasis (use gauge); data has no defined target range; fewer than 3 KPIs. Min data: Ideal for 3-10 bullet charts in a grid; scales to any count efficiently. A11y: Label every qualitative range and target with text; color is supplementary.
- **Proportional / Percentage** -> Waffle Chart (alternatif: Pictogram, Stacked Bar 100%). Jangan dipakai kalau: More than 5 categories (use stacked bar); exact values matter over visual proportion; very tight space. Min data: 10×10 grid standard (100 cells); for > 5 categories switch to stacked 100% bar. A11y: Label each category and percentage and add patterns or symbols; filled-cell color alone is insufficient.
- **Hierarchical Proportional** -> Sunburst Chart (alternatif: Treemap, Icicle, Circle Packing). Jangan dipakai kalau: More than 3 hierarchy levels (outer rings become unreadable); precision matters over overview; mobile. Min data: <100 nodes: SVG; 100-500: Canvas; >500: filter to top N before rendering. A11y: Label hierarchy levels and segments and use boundaries/patterns as well as hue; the indented list is primary. Do not rely on color alone.
- **Root Cause Analysis** -> Decomposition Tree (alternatif: Decision Tree, Flow Chart). Jangan dipakai kalau: No clear parent-child causal relationship; audience expects a summary rather than exploration. Min data: Up to 5 levels deep; limit visible nodes to 20 per level for readability; lazy-load deeper levels. A11y: Name each node and contribution and use shapes/connector styles in addition to color. Do not rely on color alone.
- **3D Spatial Data** -> 3D Scatter / Surface Plot (alternatif: Volumetric Rendering, Point Cloud). Jangan dipakai kalau: 2D projection conveys the same insight; mobile context; accessibility-required environments; standard business dashboards. Min data: WebGL required. Deck.gl: up to 1M points. Three.js: LOD required beyond 50,000 pts. A11y: Use labels, shapes, and depth-independent cues; color and 3D position cannot be the only carriers of meaning.
- **Real-Time Streaming** -> Streaming Area Chart (alternatif: Ticker Tape, Moving Gauge). Jangan dipakai kalau: Update frequency < 1/min (use periodic-refresh line chart); flashing content without reduced-motion support. Min data: Canvas/WebGL required. Buffer last 60-300s of data. Downsample older data on scroll. A11y: Show the current value and status text and use line styles or markers in addition to color. Do not rely on color alone.
- **Sentiment / Emotion** -> Word Cloud with Sentiment (alternatif: Sentiment Arc, Radar Chart). Jangan dipakai kalau: Precise values matter (word size is inherently imprecise); screen-reader context; corpus < 50 items. Min data: 50-5000 terms optimal. Beyond 5000: apply top-N filtering before render. Avoid on mobile. A11y: Expose every term, count, and sentiment as text; size and color are supplementary only.
- **Process Mining** -> Process Map / Graph (alternatif: Directed Acyclic Graph (DAG), Petri Net). Jangan dipakai kalau: No event log data available; audience expects a static flowchart (use diagram tool); node count > 100 without pre-filtering. Min data: <30 nodes: SVG; 30-100: Canvas; >100: apply variant filtering (top 80% of cases) before rendering. A11y: Label nodes and paths and use shapes/line styles in addition to color; bottlenecks require text annotations. Do not rely on color alone.
