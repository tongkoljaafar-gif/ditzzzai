# Pasangan Font (74 pairing, diringkas)

Daftar ini buat ngecek nama font yang beneran ada dan biasa dipasangkan. Bukan wajib dipakai.

## Aturan sebelum pilih

1. Cek lisensi: font Google aman; font komersial (Söhne, GT Walsheim, PP Neue Montreal, Canela) butuh lisensi, jangan diasumsikan gratis.
2. Satu display + satu body, maksimal plus satu mono. Tiga keluarga ke atas hampir selalu kacau.
3. Serif cuma buat editorial/luxury/publikasi yang beneran. Bukan default buat "kreatif".
4. `Inter` sebagai body boleh; `Inter` sebagai display tanpa alasan = keliatan template.
5. Muat font lewat `next/font` atau self-host; jangan `<link>` Google Fonts di produksi (CLS + privasi).
